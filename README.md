# dsh-toolkit

DSH（DeepSeek Harness）用着顺手的东西的落点。

规则（2026-10-21 起）：

- 后续任务里用到的工具/插件，**只要判断好用就保留**，并把它的来历、安装位置、卸载方式记进 [`TOOLS.md`](TOOLS.md)。
- 纯中间产物（下载的压缩包、解压出的临时副本、抽帧图片、一次性探针脚本、测试日志）不入库，随手清掉。
- **第三方项目不复制源码**，只记录来源、版本和本机安装位置；只有自己写的小工具才放进 `tools/`。

## 目录

| 路径 | 说明 |
|---|---|
| `TOOLS.md` | 已保留的工具/插件清单：来源、位置、用途、坑、卸载方式 |
| `tools/` | 自己写的小工具，一个工具一个目录，各自带 README |

## 加东西的流程

1. 工具装好后，把条目补进 `TOOLS.md`（来源 / 版本 / 本机路径 / 为什么留 / 怎么卸）。
2. 自己写的脚本放进 `tools/<名字>/`，附一段能跑通的用法说明。
3. 卸载一个工具时，把它从「已保留」移到 `TOOLS.md` 末尾的「已卸载」区，保留一行原因。
